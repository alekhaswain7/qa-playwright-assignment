# Playwright + TypeScript QA Automation Assignment

A small end-to-end test automation suite built using Playwright and TypeScript.

The suite covers UI automation against SauceDemo and API automation against ReqRes.

# Tech Stack

- Playwright
- TypeScript
- Node.js
- Playwright Test
- Page Object Model (POM)

# Application Under Test

### UI
https://www.saucedemo.com

### API
https://reqres.in




## Prerequisites

Make sure the following are installed:

- Node.js 18 or later
- npm
